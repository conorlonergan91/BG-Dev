Give a concise status report for the game (slug if provided: $ARGUMENTS; otherwise the most recently
modified game under `games/`).

Read `game-bible.md` and `decision-log.md` and report:
1. **Game** — title, one-line hook, current positioning (weight/count/time).
2. **Stage** — where it is in the pipeline (ideation → … → publishing) and what's done vs open.
3. **Recent decisions** — the last 3–5 from the decision log.
4. **Open questions / risks** — top 2–3 (esp. unresolved playtest questions).
5. **Recommended next step** — as an A/B/C choice with your recommendation.

Keep it to a skimmable half-screen. Then wait for the user's call.

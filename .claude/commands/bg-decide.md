description: Force a quick, focused decision to keep momentum.
argument-hint: <the question or fork you're stuck on>
---

The user wants to make a fast decision and move on. The fork is: $ARGUMENTS

As Creative Director:
1. Restate the decision in one line.
2. Lay out **2–4 concrete options (A/B/C/D)** — each a single line: the option + its main trade-off.
3. Give your **recommendation** and a one-sentence why.
4. Ask for the call (the user can pick, tweak, or say "you decide" — in which case take your own
   recommendation).
5. Once decided, **record it** in the game's `decision-log.md` (and `game-bible.md` if it changes the
   design), then state the immediate next action.

No long essays. The point is momentum.

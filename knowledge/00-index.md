# Board Game Design Knowledge Base — Index

The studio's shared reference material. Agents cite and build on these; the human can read them
directly. Core design knowledge is stable; **rankings, awards, fees, and legal/compliance specifics
change** — re-verify live (via `bg-research` / `bg-publishing`) when precision matters.

| File | Use it for |
|------|-----------|
| [`designer-profile.md`](./designer-profile.md) | **The studio's north star** — this designer's taste, favourite games, and design values. Read first; every agent biases toward it. |
| [`archetypes.md`](./archetypes.md) | Mechanism families, canonical reference games per family, and how games blend mechanisms. |
| [`reference-games.md`](./reference-games.md) | Landmark designs and what each is known for; award & ranking context. |
| [`design-fundamentals.md`](./design-fundamentals.md) | Core loop, agency, interaction, randomness, feedback loops, MDA, weight, solo/Automa. |
| [`theme-and-identity.md`](./theme-and-identity.md) | The felt identity — concept, theme, tone/vibe, story/lore, look & feel, naming. The MDA *aesthetics* leg: the kinds of fun, theme↔mechanic resonance, the restraint ladder, and keeping identity coherent while it evolves. Owned by `bg-theme`. |
| [`process-and-playtesting.md`](./process-and-playtesting.md) | The indie design pipeline, playtesting (esp. blind), and rules-writing best practice. |
| [`simulation-and-balance.md`](./simulation-and-balance.md) | Using `tools/sim` to pressure-test balance: metrics, strategy libraries, health signals, mirror probes, and the design→sim→tune loop. |
| [`elegance-and-clarity.md`](./elegance-and-clarity.md) | Keeping games at target weight and rules a joy to read: the complexity budget, the cut test, rulebook/player-aid clarity, and FAQ discipline. |
| [`modes-and-expansions.md`](./modes-and-expansions.md) | Player modes (solo/duel/multi/party), campaigns, and base-vs-expansion architecture — component reuse, playing well separately & combined, and how reference games do it. |
| [`trends-2026.md`](./trends-2026.md) | Current trends (cozy games, solo, digital prototyping, crowdfunding shift, market pressures). |
| [`manufacturing-specs.md`](./manufacturing-specs.md) | Card sizes, bleed, DPI, print-on-demand specs, Tabletop Simulator export limits. |
| [`publishing-ip.md`](./publishing-ip.md) | IP / copyright / trademark / product-safety compliance for Ireland, UK, USA. |

**Verification note:** award winners and BGG rankings are current as of 2025–2026 and should be
re-checked at query time; IP fees and safety standards change and are general information, not advice.

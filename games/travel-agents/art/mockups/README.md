# Character mock-ups — PLAYTEST PROPS, **NOT final art**

AI-generated **mock-ups** of the six characters, approved by the Creative Director for **manual
playtesting**. Committed here (an intentional exception to the "mock-ups stay gitignored" default) only so
they **persist across the ephemeral container** and the boards can re-render warm.

**Binding rails still apply:**
- **NOT final art.** Final character art is **human-illustrated**; a **paid Taiwanese cultural + language
  consultant** reviews the cast before any final/print use.
- **Never copy these into `exports/`** and never ship them as the game's real art.
- Source finals live here; `make.sh` preps them (transparent-key + fit) into gitignored `build/mockups/`
  for the board auto-embed.

Files: `FIG-CHAR-<slug>.png` — globetrotter, old-councillor, homebody, big-eater, influencer, big-brother.

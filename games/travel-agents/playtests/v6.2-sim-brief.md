## Build — rework `sim/travel_agents.py` v6.1 → v6.2
- **Region vendor markets:** a face-down vendor **deck per region**, **1–2 face-up** (North 2 / others 1),
  refill-in-place; **drinks are just the low-value vendors** in the deck.
- **The DUSK FLIP:** at dusk, clear **BOTH** the day vendor decks **AND** the day ingredient decks
  island-wide and swap in the **NIGHT decks**; players **KEEP their Larder**; the **night ingredient decks**
  use the same 5 palette but are **event-heavier** (the bustling night market). Unclaimed day vendors are gone.
- **Renewable discard:** Larder cap **7**; excess → that region's **market discard**, which **reshuffles
  back into the deck** when it runs dry (ingredients recycle — model this so the hoarder probe + supply size
  are faithful).
- **Value spread (from the content draft):** one **★ apex per region** in the night set (**E highest**); the
  **cross-region cycle N→S→E→N** with C feeding S; **drinks cheap only in C & S**.
- **Tour Tickets:** a face-up **row of 3**, claim-as-an-action, **retroactive** scoring (**+value /
  −floor(value/2)**), day/night/general pools, **draw 5-per-phase from 12**.
- **BOTH clock modes behind a knob:** **mission-clock** (completing claimed missions advances day→night→end)
  vs **all-vendor-claims clock**.
- **Strategy lineup — the five playstyles + probes:** character-lean · opportunistic · **disruptive**
  (scoped CS events at a rival) · balanced · end-game-driver — **PLUS** a **hoarder** (over-source a scarce
  signature to deny), naive baselines, and an **"ignore-objectives / ignore-drinks" control**.
- **Player count:** keep it parametrised (2/3/4) for the light seat-balance smoke below. Scaling deltas in
  the content draft's "Player-count scaling" section (mission-clock counts + mission draw grow with N).

## Cover all bases — probe suite + round-robin; report each against its bar
1. **All FIVE playstyles live?** Each real line ≤~55%, some intransitivity, all crush naive, no Condorcet crusher.
2. **Is a well-timed MIX good?** Mix ≥ the ignore-objectives/ignore-drinks control; **pure-drinks still clearly loses.**
3. **Buzz-fight frequency on the spread board** — is the headline mechanic now too **RARE**? (contested-win share; flag hard if near-zero.)
4. **Travel spread** — per-region claim/sourcing share (each ≥~18%, **East NOT starved**) + inter-region moves; confirm the cross-region cycle + rotating ★ + coverage tickets actually pull travel.
5. **Clock A/B** — mission-clock vs vendor-claim clock: which paces **~25–30 min / ~14–18 turns / ~5–6 vendors per player**? Check length variance across the random 12→5 draws. **Recommend one.**
6. **The −½ mission penalty A/B** (bg-elegance flag) — retroactive-with-penalty vs claim-or-score-0: does behaviour differ? If not, recommend **cutting it**.
7. **The dusk flip + hotter night half** — does the flip pace cleanly (no dead reset beat)? does the **event-heavier night** feel hectic-FUN not swingy-punishing (tune night event density)? should the **night half be a shorter SPRINT**?
8. **Character balance 45–55%, no dominant char × mission** — **RESOLVE H2 (大哥):** none of A/B/C was in band (58.9 / 84.6 / 30.7) → sim a **4th option** (≥1 threshold + a lighter flaw, OR ≥0 + a real brake); **buff 媽寶** (was 30%); check **網紅** (was hot); **ship 大胃王 = H1-A**. **ALSO** measure whether each kit **naturally leans day vs night** under the event-heavier night — add an explicit **day/night tweak only where a kit needs it** for the band, and note if a full **two-mode day/night FLIP** would meaningfully help (reserve as an expansion — weight cost near the elegance ceiling).
9. **Disruptive viability** — is leaning on scoped CS events a real winning lane, a trap, or oppressive? If a trap at current teeth, say what would give it teeth without feel-bad.
10. **HOARDER / ingredient-denial** — can hoarding a scarce signature **LOCK OUT** a rival's vendor/mission completion? Expected: a **trap, not a lockout** (renewable supply + cap = self-taxing) — confirm the hoarder loses, measure how much it actually **slows** a rival, and tune the **per-region signature supply size** so denial stays spice, not a stranglehold.
11. **MULTIPLAYER — a LIGHT smoke only (2p is the focus).** Run a **per-count seat-balance smoke** at 3–4p (harness `per_count` / `seat_balance`) with the scaling deltas (mission-clock counts + mission draw grow with N). 12. **Pacing / anti-runaway** — dusk/last-train counts, table-wide vs per-player, catch-up under an end-game-driver rush.

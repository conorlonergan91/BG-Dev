## 4. Techniques (the moves that produce the voice)
*<List the concrete, repeatable writing moves, each with a tiny example. Common transferable ones:>*
1. **Escalation** (rule-of-three) — small stakes raised until gloriously out of proportion.
2. **The deadpan turn** — one flat line treating the absurd as obvious.
3. **Hyper-specificity** — the real, named detail beats any invented/generic one; specificity is the warmth.
4. **Affectionate exaggeration** — inflate the *intended target* (per §1), never the dignified subject.
5. **The wink at function** — a line quietly hints why a character/card is good to play, without stating a
   rule.

## 8. Lane note (so this file stays in its lane)
- `bg-theme` owns the **naming/voice identity** (the register, locked names); this file *writes in* that
  voice — it doesn't set the identity.
- `bg-elegance` owns **rules wording that changes meaning**; `bg-rulebook` owns the rulebook as a document.
- `bg-marketing` owns **selling/positioning**; this file feeds it a consistent voice.
- `bg-continuity` guards term/name consistency — write to the canonical name table so it has less to catch.
- **Hard boundary:** this file governs *presentation words only*. A mechanics/balance/rules-logic problem
  surfaced by copy work gets **flagged** to the design side — never fixed here.
